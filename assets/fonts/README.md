# Локальные шрифты

Cormorant Garamond: normal, variable 500–600. Manrope: normal, variable 400–600.
Источник: Google Fonts CSS API, загружено 24 ноября 2026.
У каждой гарнитуры 4 поднабора: cyrillic, cyrillic-ext, latin, latin-ext.
Файлы latin-ext содержат диапазон с символом ₽. Объявления @font-face находятся в
assets/css/base/base.css; страница не обращается к внешнему сервису шрифтов.

Лицензии OFL сохранены рядом, копии в deploy/licenses/ включаются в дистрибутив.
Источники: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
и https://github.com/google/fonts/tree/main/ofl/manrope.
