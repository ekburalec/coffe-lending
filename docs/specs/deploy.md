# Публикация PHP-приложения

Активная фаза: PHP-лендинг и /admin на одном хостинге. Статическая публикация и
GitHub Pages заменены PHP-дистрибутивом по явному решению пользователя.

## Требования

Apache 2.4, mod_rewrite, AllowOverride для .htaccess, PHP 8.2+ с pdo_sqlite, DOM,
mbstring, fileinfo, GD с WebP и ZipArchive. HTTPS обязателен для боевого сайта.
Сайт устанавливается в корень домена, подкаталоги не поддерживаются. Настройка
Nginx не входит в текущий вариант: требуется эквивалент закрытия служебных каталогов
и передачи маршрутов в index.php. Проверка окружения — bin/doctor.php.

## Сборка

1. В config/deploy.php указать site_url без пути; без домена разрешён только noindex.
2. `php bin/build-dist.php` создаёт dist/, используя изолированную БД из seed.json.
3. Проверяется SEO исходной редакции, объединяются CSS/JS и получают ?v=хэш.
4. Копируются только runtime-код, шаблоны, конфигурация, CLI установки, используемые
   ресурсы и лицензии. Рабочие данные, аккаунты, загрузки, копии, docs и .git исключены.
5. Проверить dist с временными APP_DATA_DIR/APP_UPLOAD_DIR и tests/integration.py.

Сборка удаляет только dist внутри проекта, не coffee-data и не var. Удаление
защищено проверкой абсолютного пути. dist руками не редактируется и не хранится в git.

## Первая установка

1. Выгрузить содержимое dist (включая .htaccess, .user.ini) в public_html/корень сайта.
2. Приватное хранилище по умолчанию — соседний coffee-data вне public_html.
   При необходимости задать абсолютные APP_DATA_DIR/APP_UPLOAD_DIR в окружении PHP.
   Нельзя размещать приватные данные в публичном каталоге на боевом хостинге.
3. Дать пользователю PHP права записи только в приватное хранилище и каталог фото.
4. Через SSH/терминал хостинга выполнить `php bin/migrate.php`; один раз импортируется
   исходная редакция. Повторный запуск сохраняет рабочие данные.
5. Создать администратора bin/create-admin.php (пароль через stdin), проверить doctor.
6. Установить HTTPS. Проверить Secure/HttpOnly/SameSite cookie, display_errors=Off,
   корректный upload_tmp_dir, лимиты загрузок и свободное место. .user.ini рассчитан
   на PHP-FPM/CGI; при mod_php эквивалентные параметры задаются в панели/конфигурации PHP.
7. Заменить демо-адрес/телефон и другие сведения на реальные, добавить реальную карту.
8. Проверить главную и все редакторы, загрузить фотографию, сделать и восстановить
   тестовую копию на отдельной установке.

## Обновление

Сначала скачать полный архив и сохранить снаружи хостинга. Выгрузить новый код из
dist, сохраняя приватный coffee-data. При изменении путей передать старые значения
APP_DATA_DIR/APP_UPLOAD_DIR. Запустить миграции и doctor; проверить существующие данные.
Не копировать локальную var или готовую БД поверх рабочей. Устаревший index.html
от статической версии удалить после резервной копии: DirectoryIndex теперь index.php.

## HTTP и SEO

.htaccess закрывает app/templates/config/bin/var и опасные расширения; каждый
служебный каталог также получает собственный Require all denied. Индексы каталогов
отключены. Загруженные фото находятся вне публичного корня и выдаются контроллером.
Проверить на хостинге 403/404 для config/seed.json, bin/migrate.php, app, templates,
.git, .user.ini и предполагаемых путей БД/копий. Эти файлы не должны скачиваться.
Локальный router.php реализует тот же белый список для PHP built-in server.

robots.txt, sitemap.xml, llms.txt и llms-full.txt — живые маршруты, поэтому изменения
в админке не оставляют устаревший статический контент. noindex: robots запрещает
обход, meta robots noindex/nofollow, sitemap возвращает 404. При публичном режиме
формируются canonical, абсолютные OG/JSON-LD и sitemap, robots исключает /admin.
Админка всегда noindex/no-store. Свободные SEO-тексты проверяются после изменения.

## Definition of Done

- [ ] Сборка, lint и интеграционные тесты исходников/dist прошли.
- [ ] На целевом хостинге подтверждены PHP, расширения, mod_rewrite и HTTPS.
- [ ] Служебные файлы и приватное хранилище недоступны по HTTP.
- [ ] Аккаунт создан без пароля по умолчанию; вход/выход и загрузки проверены.
- [ ] Рабочие данные переживают обновление кода.
- [ ] Копия сохраняется и восстанавливается в отдельное окружение.
- [ ] Домен, реальные контакты и режим индексации проверены.
- [ ] Адаптив, клавиатура, консоль и ресурсы проверены на собранном сайте.

Публикация на внешний хостинг не выполнялась: хостинг и домен не предоставлены.
