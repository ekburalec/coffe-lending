## Исправления окружения Windows

В build-dist.php сравнение разрешённого пути dist использует DIRECTORY_SEPARATOR.
Защитная проверка по-прежнему разрешает удаление только dist внутри текущего проекта.
В build-og-image.php добавлены стандартные пути Chrome для Windows и безопасная
очистка собственного временного профиля средствами PHP вместо команды rm.
В данном окружении GD включается параметром -d extension=gd; настройки системного PHP не менялись.
