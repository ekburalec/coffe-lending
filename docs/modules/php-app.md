# PHP-приложение

Запуск исходников: `php -S localhost:8090 router.php`. PHP 8.2+, DOM, PDO SQLite,
GD с WebP и ZipArchive. `index.php` задаёт HTTP-заголовки, bootstrap подключает
конфигурацию и обработчик ошибок, роутер выбирает контроллер. Шаблоны только
выводят переданные данные. Неизвестные маршруты — 404 без раскрытия файлов.
APP_DATA_DIR задаёт приватный каталог данных; APP_UPLOAD_DIR — каталог фото. В исходниках по умолчанию var/media, в релизе coffee-data/media вне публичного корня.
Главная использует templates/landing.tpl и подготовленные данные landingData(). Начальная редакция данных — config/seed.json, история статической страницы доступна в git. Подкаталоги установки не поддержаны.
