# Визуальный редактор

## Устройство

По уточнению пользователя от 28 ноября 2026 редактор работает на самом сайте.
После успешного входа открывается GET /. Авторизованный администратор видит
верхнюю панель templates/partials/visual-editor.tpl внутри фиксированной шапки.
Гость получает прежний лендинг без интерфейса, состояния и меток редактора.
GET /admin/visual-editor и /admin/visual-editor/preview оставлены для прежних ссылок:
после проверки входа они перенаправляют на /. Отдельной страницы и iframe нет.

GET /admin/visual-editor/session возвращает текущий CSRF либо JSON 401.
POST /admin/visual-editor/save принимает multipart changes и photo_image-0/1.
app/controllers/landing.php включает редактор только после проверки сессии;
app/controllers/visual-editor.php проверяет доступ и организует сохранение;
app/services/visual-editor.php готовит/очищает пакет, версии, типографику и файлы;
app/models/visual-editor.php выполняет транзакционную запись.
Реестр — config/visual-editor.php. Хранение — прежние records content/images.

assets/js/modules/visual-editor.js экспортирует initVisualEditor из main.js.
Модуль работает с текущим document и завершает инициализацию сразу, если панели нет.
assets/css/blocks/visual-editor.css подключён в main.css, токены в base/vars.css.
build-php.php включает реестр, код и шаблоны; JS собирается штатным графом импортов.

## Интерфейс и доступность

Кнопка «Редактор сайта» вверху переключает редактирование и обычный просмотр.
При входе редактирование включено. В режиме просмотра скрыты инструменты и контуры,
возвращены исходные роли и порядок фокуса; несохранённый ввод остаётся на странице.
Состояние кнопки отражено в aria-pressed/expanded, связь — aria-controls.
«Админка» и «На сайт» переводят текущую вкладку, дополнительных вкладок не создают.
Ссылка «Изменить на странице» ведёт на /#ключ, редактор фокусирует нужный фрагмент.

Разрешённые тексты/фото подсвечены; есть отметки изменений, счётчик, общие
сохранение/отмена. Жирный/курсив кнопками и Ctrl+B/Ctrl+I; Ctrl+S сохраняет набор
вне диалогов. Вставляется обычный текст; окончательная очистка — на сервере.
Заголовки вкладок поводов — зеркала одного ключа, вкладки остаются рабочими.
Стрелки CTA и структура находятся вне редактируемого фрагмента.

Редактируемые фрагменты доступны через Tab, textbox/aria-multiline и подпись.
Фото открывается мышью или Enter/Space. Нативный dialog имеет подписанные поля,
превью, видимую ошибку и возврат фокуса. Подсказки управляемых данных доступны
с клавиатуры; ссылка ведёт в прежнюю форму. Структурированные данные по-прежнему
изменяются в своих разделах админки.

Сайт использует реальную ширину окна, переключателей искусственного размера нет.
Панель адаптируется от 320px. Компенсация высоты шапки учитывает панель, сообщения
и раскрытие/сворачивание инструментов; якоря остаются доступны. Уведомления через
notify.js; постоянная aria-live область оставляет текст ошибки.

## Защита и фото

Авторизация/таймаут/отзыв сессии общие с админкой. Cookie HttpOnly/SameSite=Strict,
Secure при HTTPS, Path=/ для доступа на сайте. Следующий запрос к /admin переносит
прежнюю cookie Path=/admin на / с тем же ID и удаляет прежнюю область.
Без cookie лендинг не запускает сессию и не устанавливает cookie.
Ответ сайта содержит Vary: Cookie; при проверке сессии — no-store/noindex.
Авторизованный HTML с состоянием редактора не попадает в публичный кеш.

POST+CSRF, серверный список ключей, пределы размера, версии. Ответы
401/403/409/422/500 не сбрасывают черновик. Все страницы запрещают встраивание
через frame-ancestors none. Blob-картинки разрешены только авторизованному
лендингу для локальных превью. Метки и интерфейс отсутствуют в гостевом HTML.

Файлы до общего сохранения локальны. Загрузчик проверяет JPG/PNG/WebP до 10 МБ,
100×100–20 МП, создаёт WebP 720×540 и 1440×1080 с центральным кадрированием,
без метаданных. Ручное кадрирование не добавлено. Старые файлы сохраняются для копий.

## Проверки

- python tests/visual-editor-http.py: изолированные авторизация, отсутствие панели/
  cookie у гостя, перенос старой сессии, CSP/CSRF, типографика, атомарность текста/
  фото, WebP/retina, конфликты, старый текст и копии.
- python tests/visual-editor-http.py --serve: временный стенд на 8096;
  реквизиты/каталог данных только в игнорируемом var/visual-editor-browser.json.
  COFFEE_VISUAL_TEST_PORT меняет порт; COFFEE_TEST_ROOT выбирает исходники/dist.
- tests/visual-editor-browser.cjs: playwright-cli run-code после входа; работа на /,
  верхняя панель без iframe, ввод/форматирование/фото/публикация/отмена, режимы,
  переходы в той же вкладке, компенсация шапки, 320–1440px и сбой сети.
- tests/visual-editor-accessibility-browser.cjs: клавиатура, диалог фото, ошибки,
  возврат фокуса, выход и публичный no-JS.
- tests/visual-editor-typing-browser.cjs: посимвольный ввод, вставка обычного текста,
  отсутствие ложной ошибки загрузки и снимки desktop/mobile.
- tests/visual-editor-recovery-browser.cjs: конфликт вкладок и истёкшая сессия;
  оставляет черновик для проверки повторного входа в соседней вкладке.
- tests/integration.py и прежние браузерные сценарии проверяют регрессии.

Рабочие данные не меняются тестами. Публикация на внешний хостинг не выполняется.
