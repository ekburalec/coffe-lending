# Изображения лендинга

Реестр растровой графики: фото, сгенерированные картинки, предметная съёмка.
На каждую картинку — бриф, чтобы её можно было переснять или перегенерировать в том же стиле.
Стиль графики — из [direction.md](direction.md), раздел «Формы и геометрия».

## Правила

- **Формат:** WebP. Прозрачный фон — WebP с альфой. Картинка превью ссылки — отдельно,
  JPG 1200×630 ([og-image/README.md](og-image/README.md)).
- **Retina обязательна** ([docs/specs/html.md](../specs/html.md), «Изображения»): рядом лежат
  `name.webp` (1x) и `name@2x.webp` (вдвое больше по каждой стороне). 1x — примерно самый
  крупный размер картинки на странице в CSS-пикселях. 1x получаем из 2x уменьшением вдвое
  через GD (с сохранением прозрачности), качество WebP ≈ 82.
- **Где лежат:** `assets/img/` — по смыслу в подпапках (`assets/img/products/`, `assets/img/team/`).
  Имена — латиницей, kebab-case, по смыслу (`hero.webp`, `step-delivery.webp`).
- **Сгенерированная графика:** промпт сохраняется здесь целиком. Исходники генерации
  (PNG большого размера) в проект не кладутся.
- **Чужие фото:** только с правом использования; источник и лицензия — в брифе.
- В `dist/` попадает только картинка, на которую есть ссылка (`docs/specs/deploy.md`).
