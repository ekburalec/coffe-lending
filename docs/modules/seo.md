# SEO управляемого лендинга

Редактор /admin/edit?section=seo: title, description, OG title/description и JPG
1200×630. При загрузке JPG/PNG/WebP сервер создаёт JPG нужного размера. Свободные
SEO-тексты не содержат автоматических подстановок; цены выводятся в структурированном
меню и priceRange из текущих товаров. Из начального description удалена фиксированная
цена, чтобы изменения каталога не оставляли старое обещание.
JSON-LD: CafeOrCoffeeShop, адрес, график/особые даты, Menu/MenuSection/MenuItem/Offer,
FAQPage из видимых ответов. Нет выдуманного рейтинга. JSON_HEX_* предотвращают выход
из script при вводе HTML. Вывод атрибутов экранирован. site_url и noindex задаются
в config/deploy.php; без домена разрешён только предварительный режим.

robots.txt, sitemap.xml, llms.txt и llms-full.txt — динамические маршруты, поэтому
после правок в админке обновляются без сборки. Манифест использует актуальное имя.
