# Заказы в админке

/admin/orders: список с поиском, фильтрами и пагинацией; карточка по id, история,
правки, статусы и печать. /admin/orders?board=1: доска, фильтр способа получения,
до 50 карточек колонки, полные счётчики. Выбор статуса работает без перетаскивания.
Все изменения требуют авторизации, POST, CSRF и версии заказа.
Счётчик новых заказов обновляется периодически; ошибки связи видны.
Отмена и возврат в работу доступны через карточку с пояснением.

При восстановлении копии очистить очередь писем и выполнить очистку ПД.
Проверки: tests/orders.php и tests/orders-http.py, изолированная БД.
