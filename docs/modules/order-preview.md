> PHP-фаза: карточки и строки корзины теперь формируются из SQLite. JS читает цены и тарифы из серверного HTML; заказ по-прежнему локальный. Скрытые категории/товары не выводятся, отсутствующий товар нельзя добавить.

# Локальный состав заказа

Реализация: assets/js/modules/order-preview.js, initOrderPreview(), импорт из main.js.
Бизнес-правила: [order-preview.md](../product/logic/order-preview.md).

## Данные и разметка

Товары и строки состава заранее находятся в index.html. Названия читаются из
data-product-name, цены из value элемента data с data-unit-price. JavaScript
не создаёт меню и не хранит копию каталога. Количество хранится только в памяти,
после перезагрузки состав пустой. localStorage, cookies, отправки и оплаты нет.

Корневой data-order-preview хранит стоимость доставки, порог бесплатной доставки
и шаблоны подписей. Все суммы считаются в целых рублях. Доставка начисляется
только для непустого состава, выбранной доставки и суммы товаров ниже порога.

Корень теперь является dialog: [боковая корзина](order-drawer.md).
Пустой состав скрывает панель расчёта. Миниатюры товаров находятся в assets/img/order/,
используются фото 80×80 и retina 160×160 из исходных изображений меню.

## Поведение

- Добавление, увеличение, уменьшение и удаление через data-order-*.
- Уменьшение до нуля удаляет позицию. Отрицательного количества нет.
- Счётчик в шапке показывает сумму единиц, а не число уникальных товаров.
- Строки скрываются атрибутом hidden, названия и цены остаются в HTML.
- Итог объявляется через output с aria-live; сообщения проходят через notify.js.
- При удалении строки фокус переходит на следующую доступную строку,
  а после удаления последней позиции на ссылку пустого состояния.
- Без JS кнопки добавления и выбор получения скрыты. Меню, составы и цены читаются.

## Проверки

Проверены суммы 0, 190, 670, 1000 и 1190 ₽, самовывоз и доставка,
смена тарифа на границе 1000 ₽, изменения количества, удаление и возврат фокуса.
Собранный dist проверен отдельно. Результаты: [qa-report.md](../product/qa-report.md).
