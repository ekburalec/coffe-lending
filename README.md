# Coffe & Go

Адаптивный статичный лендинг кофейни: HTML5, чистый CSS и нативные ES-модули.
Точка входа — `index.html`. PHP, база данных и серверная отправка форм отложены
по прямому решению пользователя.

## Локальный просмотр

В корне проекта:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).
Подойдёт и другой статический HTTP-сервер, например Live Server.
HTTP нужен для нативных ES-модулей; прямое открытие через `file://` ограничивает JS в браузерах.
Сборка и установка npm-пакетов не требуются.

## Что работает

- Переходы по разделам, мобильное меню, закрытие по Escape и выбору ссылки.
- Фиксированная шапка с плавным появлением тени при прокрутке;
  отступы страницы и якорей учитывают её высоту.
- Фильтры меню: 18 позиций, категории и популярные позиции по умолчанию.
- Кнопки покупки, варианты фасовки и помола, корзина с количеством и итогом.
  Корзина сохраняется локально. Интерфейс самовывоза готов; заказ ещё не отправляется.
- В подвале — заглушки ВК, ОК, Telegram и WhatsApp.
- У всех позиций меню есть изображения. Для 10 дополнительных напитков созданы
  отдельные фото; для отсутствующих и сломанных картинок предусмотрены замены товара и аватара.
- FAQ и раскрытие состава собственного подарка через нативный `details`.
- Проверка email и согласия в форме. Адрес не отправляется, подписка не создаётся.
  Надпись «Подписка скоро откроется» удалена по просьбе пользователя.
- Без JS доступны вся навигация, все позиции меню и FAQ; отправка формы заблокирована.
