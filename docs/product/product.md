## Части системы

**Фаза 1:** статичный лендинг `index.html` по стеку шаблона (HTML + CSS + JS, сборка `dist/`).

- **Лендинг** — одна страница: какие блоки (структура — [landing-content.md](landing-content.md)).
- **Целевое действие** — как работает CTA технически.
- **Интеграции** — карты, сервис форм, аналитика, виджеты (каждая описывается в `docs/integrations/`).
- **Серверная часть** — нет / нужна (тогда — [docs/specs/php.md](../specs/php.md), решение пользователя).
