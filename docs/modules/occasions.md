# Выбор повода

Шаблон partials/occasions.tpl выводит три сценария с существующими текстами,
переходами и изображениями. landingData подбирает первый доступный товар кофе/чая,
предпочитая фото перед заглушкой. Если категория скрыта, CTA ведёт в #menu;
если товара нет, используется фото пространства. Цена/порция из SQLite, не из JS.

occasions.js превращает кнопки в доступные tabs/tabpanel: одна активная панель,
aria-selected/controls/labelledby, один tab stop. Клик и стрелки Left/Right,
Home/End переключают сценарий. Без JS кнопки скрыты, все статьи видны с заголовками
и ссылками. Ничего не отправляется и не сохраняется. Reduced-motion отключает
переход цветов. На узком экране кнопки идут друг под другом, панель в одну колонку.
Проверки: tests/landing-interactions-browser.cjs, включая no-JS и 320/768/1440.
