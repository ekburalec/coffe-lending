# Global Definition of Done

Эти критерии применяются ко всем задачам проекта.

## Всегда

- [ ] Код соответствует стеку (статический HTML, чистый CSS, нативный JS, сборка `bin/build-dist.php`)
- [ ] Код соответствует спекам из `docs/specs/` и правилам из `docs/ai-rules/`
- [ ] Тексты блоков взяты из `docs/product/landing-content.md`, факты — из `docs/product/product.md`
- [ ] Нет критических ошибок в консоли браузера и 404 в Network
- [ ] Вёрстка по BEM, нет inline-стилей и inline-скриптов
- [ ] Цвета, отступы, шрифты, радиусы — только переменными из `vars.css`
- [ ] Интерфейс адаптивен (desktop + mobile от 320px)
- [ ] Доступность: работа с клавиатуры, видимый фокус, контраст WCAG 2.1 AA, `alt` у картинок
- [ ] У растровых картинок есть retina-версия `@2x`
- [ ] Базовые сценарии проверены вручную
- [ ] Нет неиспользуемых файлов и мёртвого кода
- [ ] Новая или изменённая бизнес-логика зафиксирована в `docs/product/logic/`
      и внесена в таблицу «Бизнес-логика» в `AGENTS.md`
- [ ] Новый модуль описан в `docs/modules/`, новая интеграция — в `docs/integrations/`,
      обе внесены в соответствующие таблицы `AGENTS.md`

## Формы

- [ ] Поля с `<label>`, ошибки связаны через `aria-describedby`, состояния отправки видны
- [ ] Клиентская валидация — только UX; данные проверяет тот, кто их принимает
      (сторонний сервис или серверная часть по `docs/specs/php.md`)

## Перед публикацией

- [ ] DoD из `docs/specs/deploy.md` выполнен: `php bin/build-dist.php` без ошибок,
      SEO-предупреждений нет или каждое осознанно оставлено

## Если у проекта есть серверная часть (по решению пользователя)

- [ ] Код соответствует `docs/specs/php.md` (PHP 8, SQLite, PDO)
- [ ] Нет PHP ошибок и warnings
- [ ] Формы валидируются на сервере
- [ ] Загружаемые файлы проверяются (тип, размер), имена санитизируются
- [ ] Все SQL-запросы через PDO с параметрами (без конкатенации переменных в запрос)
- [ ] Шаблоны `.tpl` не содержат бизнес-логики
- [ ] Изменения схемы БД отражены в `docs/app/database-schema.md`
