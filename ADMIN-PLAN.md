# План внедрения PHP-админки

Решение пользователя: PHP-сайт и `/admin` на одном хостинге, SQLite, один
администратор. Общие данные выводятся из настроек; свободные тексты редактируются
вручную. Все согласованные возможности включены, кроме меток товаров.
Реальные заказы и оплата не входят в задачу. Демо-данные сохраняют свой статус.

Этапы выполняются строго по порядку. Каждый этап — отдельный коммит с кодом,
документацией, проверками и обновлением этого файла. Галочка ставится только
после проверки результата. Первоначально все пункты не отмечены.

- [ ] 1. Спецификация — поля, зависимости, архитектура, критерии приёмки и правила проекта.
  Коммит: `docs: specify PHP admin scope and architecture`.
- [ ] 2. Основа PHP — фронт-контроллер, роутер, шаблоны, ошибки и настройки; проверка запуска.
  Коммит: `feat: add PHP application foundation`.
- [ ] 3. SQLite — схема, миграции, импорт текущего контента без перезаписи при повторном запуске.
  Коммит: `feat: add SQLite schema and initial content`.
- [ ] 4. Авторизация — CLI-создание администратора, вход, выход, сессии, CSRF, ограничение попыток.
  Коммит: `feat: add secure admin authentication`.
- [ ] 5. Каталог — категории, товары, цены, состав, порции, порядок, видимость, наличие и WebP 1x/2x.
  Коммит: `feat: add catalog and product image management`.
- [ ] 6. Контакты и график — адрес, телефон, карта, расписание по дням, исключения по датам.
  Коммит: `feat: add contacts and opening hours management`.
- [ ] 7. Получение — тарифы, порог, зона, сроки, включение самовывоза и доставки.
  Коммит: `feat: add pickup and delivery settings`.
- [ ] 8. Контент — тексты, изображения, навигация, FAQ, объявления по датам, отзывы и рейтинг.
  Коммит: `feat: add landing content and navigation management`.
- [ ] 9. Лендинг — серверный вывод всех управляемых данных, согласованная корзина, без JS читается меню.
  Коммит: `feat: render landing from managed content`.
- [ ] 10. SEO — title, description, Open Graph, превью и JSON-LD из актуальных данных.
  Коммит: `feat: add SEO and social preview management`.
- [ ] 11. Копии — экспорт БД и полного архива, проверка восстановления, предварительная копия текущих данных.
  Коммит: `feat: add backup and restore tools`.
- [ ] 12. Публикация — PHP-дистрибутив, закрытые служебные файлы, сохранность данных, установка и итоговые проверки.
  Коммит: `build: prepare PHP deployment and release checks`.

## Проверки перед сдачей

- [ ] PHP lint и автоматические интеграционные проверки успешно завершены.
- [ ] Авторизация, CSRF, валидация и ограничения загрузок проверены.
- [ ] Все разделы редактирования работают, изменения отражаются на странице.
- [ ] Корзина: пустая, самовывоз, доставка ниже/на/выше порога, недоступные товары.
- [ ] Особый график и объявления корректны на границах дат в часовом поясе кофейни.
- [ ] Резервная копия восстановлена в изолированную тестовую среду.
- [ ] Исходники и дистрибутив проверены; служебные данные недоступны по HTTP.
- [ ] Мобильная версия от 320px, клавиатура, фокус и отсутствие ошибок ресурсов проверены.

## Журнал выполнения

План создан до начала реализации. Незавершённые проверки и ограничения записываются здесь явно.
