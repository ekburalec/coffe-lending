# Визуальное редактирование

Решение пользователя от 28 ноября 2026: редактирование текста на самом лендинге,
жирный/курсив, alt и замена фото самостоятельных блоков. В нижней отдельной группе
меню сначала «Пароль», затем «Визуальный редактор». По уточнению пользователя
редактирование выполняется на самом сайте после входа: панель находится сверху,
отдельная страница редактора и iframe исключены. Пункт админки ведёт на сайт
в текущей вкладке. Гостям панель и редактируемые метки не выводятся.

## Границы

config/visual-editor.php содержит закрытый список content/images: первый экран,
общие заголовки и вводные, карточки поводов, пространство, свободные примечания/CTA.
Общие заголовки FAQ/отзывов разрешены, их записи исключены. Каталог, категории,
контакты, часы, доставка, соцсети, навигация, объявления, рейтинг и фотографии этих
данных меняются в прежних формах. Рекомендации в поводах читают товары из каталога.
Подсказка и переход к форме доступны по наведению, фокусу, клику и клавиатуре.

## Публикация

Разрешены strong/em/br без атрибутов, b/i нормализуются; другие теги/ссылки/стили
не сохраняются, исполняемое содержимое удаляется. Текст обязателен, до 5000 символов;
alt обязателен, до 300. При сохранении добавляются неразрывные пробелы после коротких
слов и между числом и единицей. Старые обычные строки экранируются и не меняются.

Правки и файлы остаются в браузере до общей кнопки «Сохранить». «Применить к странице»
меняет только черновик фото; «Отменить» возвращает последнее подтверждённое состояние.
Один ключ может повторяться в разных местах, все отображения синхронизируются.
Кнопка «Редактор сайта» переключает правку и обычный просмотр без перезагрузки
и сброса ввода. Ширина сайта соответствует настоящему окну браузера.

Сервер проверяет весь пакет и версии, затем проверяет и конвертирует файлы.
Все records записываются одной транзакцией SQLite. При отказе удаляются только
файлы этой попытки. Старые фото остаются для копий. Частичной публикации нет.
Следующий публичный HTTP-запрос видит новые данные; открытая вкладка обновляется вручную.

## Конфликты и уход

SHA-256 полного представления records проверяется для изменяемых ключей; конфликт
возвращает 409. Независимые поля не конфликтуют. Обычные формы content/images
также передают версию. Форматированный текст открывается в визуальном редакторе:
обычная форма не стирает выделение.

Сеть/401/403/409 оставляют ввод. После входа в новой вкладке редактор получает
текущий CSRF и позволяет сохранить оставшийся черновик. Переходы/выход предлагают
сохранить, отменить или остаться. Закрытие/перезагрузка использует beforeunload;
после закрытия вкладки черновик не хранится. Если ответ потерян после серверной
записи, повтор может дать конфликт: нужно скопировать ввод перед обновлением.

## Совместимость

Таблицы/журнал схемы не меняются. format=text по умолчанию, format=inline явно
включает безопасное оформление. space-fact-1/2/3 и reviews-title могут отсутствовать
в старой БД/копии: вывод подхватывает seed, migrate добавляет отсутствующее без
перезаписи. Остальные требования к старым копиям сохранены. inline в копиях
проверяется на точное соответствие очищенному HTML.
