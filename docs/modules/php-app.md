# PHP-приложение

Запуск исходников: `php -S localhost:8090 router.php`. PHP 8.2+, DOM, PDO SQLite,
GD с WebP и ZipArchive. `index.php` задаёт HTTP-заголовки, bootstrap подключает
конфигурацию и обработчик ошибок, роутер выбирает контроллер. Шаблоны только
выводят переданные данные. Неизвестные маршруты — 404 без раскрытия файлов.
APP_DATA_DIR задаёт приватный каталог данных; APP_UPLOAD_DIR — каталог фото.
Главная использует templates/landing.tpl и подготовленные данные landingData(). Исходная статическая редакция сохранена в config/initial.html только для истории импорта. Подкаталоги установки не поддержаны.
