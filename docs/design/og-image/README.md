# Картинка превью ссылки (`og:image`)

Картинка, которую показывают Telegram, WhatsApp, VK, соцсети и поисковики, когда кто-то
делится ссылкой на сайт. Подключена в `<head>` `index.html` как `og:image`.

| | |
|---|---|
| Файл | `assets/img/og-image.jpg` — JPG 1200×630 (1,91:1), прогрессивный, качество 86 |
| Шаблон | `docs/design/og-image/og-image.html` — обычная HTML-страница 1200×630 |
| Сборка | `php bin/build-og-image.php` — снимок шаблона headless Chrome, перевод в JPG через GD |

## Что на картинке

Слева — название, надзаголовок, оффер первого экрана, подзаголовок и два факта.
Справа — место под визуал (фото товара, скриншот, знак).

**В шаблоне проекта это нейтральная заглушка.** Тексты берутся с первого экрана лендинга
(`docs/product/landing-content.md`), цвета и шрифты — из `assets/css/base/vars.css` и
`assets/fonts/`; они продублированы в шаблоне, чтобы он был самодостаточным.

## Как поменять

1. Поправить `og-image.html` (тексты, цвета, композицию). Открыть его в браузере —
   он показывается ровно в размере картинки.
2. `php bin/build-og-image.php`. Нужен Google Chrome или Chromium; если он не в стандартном
   месте — `CHROME_PATH=/путь/к/chrome php bin/build-og-image.php`.
3. Посмотреть `assets/img/og-image.jpg`: текст не переносится и не обрезается, фото целиком.
4. Пересобрать `dist/` и выгрузить. Мессенджеры кешируют превью: чтобы показать новое сразу,
   сохрани картинку под новым именем и поправь `og:image` (или сбрось кеш в @WebpageBot
   для Telegram и в Sharing Debugger для Facebook).

Важные зоны: в узких превью (WhatsApp, VK) края могут срезаться — ключевой текст держится
не ближе 56 px к краям.

Шаблон в `dist/` не попадает: на него нет ссылок со страниц сайта.
