# CSS-переменные компонентов — как описывать цвета

## Зачем

CSS-переменные наследуются по дереву DOM. Если переменная объявлена прямо на элементе (`component { --var: value }`), она побеждает унаследованное значение от предка. Из-за этого переопределение на контейнере (`parent { --var: other }`) не сработает — компонент подавит его своим собственным объявлением.

Чтобы контейнеры могли управлять внешним видом дочерних компонентов, переменные должны быть объявлены в `:root`. Тогда любой предок может переопределить значение, а компонент получит его через наследование.

---

## Правило: три уровня

```
:root              ← дефолтные значения всех переменных компонента
.component         ← только использует переменные, не объявляет их
.context           ← переопределяет нужные переменные для своего контекста
```

---

## Пример: кнопка `.btn--ghost`

### 1. Дефолты в `:root`

```css
:root {
    --btn-ghost-color:        var(--color-text-primary);
    --btn-ghost-bg:           transparent;
    --btn-ghost-border:       transparent;
    --btn-ghost-hover-color:  var(--color-text-primary);
    --btn-ghost-hover-bg:     var(--color-bg-secondary);
    --btn-ghost-hover-border: transparent;
    --btn-ghost-active-bg:    var(--color-bg-tertiary);
}
```

### 2. Компонент только читает переменные

```css
.btn--ghost {
    background-color: var(--btn-ghost-bg);
    color: var(--btn-ghost-color);
    border-color: var(--btn-ghost-border);
}

.btn--ghost:hover {
    background-color: var(--btn-ghost-hover-bg);
    color: var(--btn-ghost-hover-color);
    border-color: var(--btn-ghost-hover-border);
}

.btn--ghost:active {
    background-color: var(--btn-ghost-active-bg);
}
```

### 3. Контекстное переопределение

Тёмный баннер `.hero-banner` переопределяет переменные для белого текста на кнопке:

```css
.hero-banner {
    --btn-ghost-color:        rgba(255, 255, 255, 0.80);
    --btn-ghost-border:       rgba(255, 255, 255, 0.25);
    --btn-ghost-hover-color:  #ffffff;
    --btn-ghost-hover-bg:     rgba(255, 255, 255, 0.10);
    --btn-ghost-hover-border: rgba(255, 255, 255, 0.40);
    --btn-ghost-active-bg:    rgba(255, 255, 255, 0.15);
}
```

Кнопка `<a class="btn btn--ghost">` внутри `.hero-banner` автоматически получает белый цвет — разметка не меняется.

## Именование переменных

```
--{компонент}-{свойство}
--{компонент}-{состояние}-{свойство}
```

Где `{компонент}` — это имя CSS-класса компонента, `{свойство}` — сокращённое название CSS-свойства.

| Состояние | Суффикс |
|-----------|---------|
| Базовое   | (без суффикса) |
| Hover     | `-hover-` |
| Active    | `-active-` |

Свойства: `color`, `bg`, `border`.

**Примеры:**
- `--btn-ghost-color` — цвет текста кнопки ghost в базовом состоянии
- `--btn-ghost-hover-bg` — фон кнопки ghost при наведении
- `--btn-primary-active-border` — рамка кнопки primary при нажатии

## Переменные для компонентов с составным именем

Если CSS-класс компонента состоит из нескольких слов (например, `.post-card`), переменные именуются по формату:

```
--{класс-компонента}-{свойство}
```

Имя класса полностью переносится в название переменной:

```css
/* Компонент .post-card */
--post-card-bg
--post-card-color
--post-card-border-color
```

Разрыва между именем компонента и свойством нет — весь токен читается как единое целое.

### Пример: компонент `.post-card`

```css
/* vars.css */

/* --------------------------------------------------------------------------
   post-card
-------------------------------------------------------------------------- */
:root {
    --post-card-bg:           #ffffff;
    --post-card-border-color: #E8E8E8;
    --post-card-color:        var(--color-text-primary);
    --post-card-desc-color:   var(--color-text-muted);
}

.dark-mode {
    --post-card-bg:           #252932;
    --post-card-border-color: transparent;
}
```

```css
/* post-card.css */
.post-card {
    background-color: var(--post-card-bg);
    border-color:     var(--post-card-border-color);
    color:            var(--post-card-color);
}
```

## Где хранятся переменные

Все компоненты без исключения — переменные хранятся в `assets/css/base/vars.css` отдельным именованным блоком.

### Структура блока в `vars.css`

```css
/* --------------------------------------------------------------------------
   {Название компонента}
-------------------------------------------------------------------------- */
:root {
    --{компонент}-{свойство}: {значение};
}

.dark-mode {
    --{компонент}-{свойство}: {тёмное значение};
}
```

**Пример — логотип:**

```css
/* --------------------------------------------------------------------------
   logo
-------------------------------------------------------------------------- */
:root {
    --logo-color: #000;
}

.dark-mode {
    --logo-color: #fff;
}
```

Каждый компонент — свой блок. Светлые значения в `:root`, тёмные в `.dark-mode`. Никаких переменных компонента в других местах.

---

## Dark mode

Тот же механизм — переопределение на уровне контейнера темы. Тёмные значения объявляются
на самом `.dark-mode`, в блоке компонента в `vars.css`, а не на селекторе компонента внутри темы:

```css
/* vars.css */

/* --------------------------------------------------------------------------
   btn
-------------------------------------------------------------------------- */
:root {
    --btn-primary-color: #ffffff;
    --btn-dark-bg:       #111111;
    --btn-dark-color:    #ffffff;
}

.dark-mode {
    --btn-primary-color: #111111;
    --btn-dark-bg:       #f0f0f0;
    --btn-dark-color:    #111111;
}
```

Запрещено — так тема «лезет внутрь» компонента и объявляет переменные на его элементе:

```css
.dark-mode .btn--primary {
    --btn-primary-color: #111111;
}
```

---

## Правила

1. **Дефолты — только в `:root`.** Компонент никогда не объявляет свои переменные в своём селекторе.
2. **Компонент только читает.** Все `var(--btn-*)` — только в свойствах (`color:`, `background-color:`, `border-color:`), не в объявлениях переменных.
3. **Контекст переопределяет на своём уровне.** `.hero-banner`, `.card`, `.dark-mode` и т.д. — переопределяют переменные у себя, не лезут внутрь компонента.
4. **Покрывать все состояния.** Для каждого варианта — переменные для base, hover и active.
5. **Переменные хранятся в `vars.css`.** Для всех компонентов без исключения, включая кнопки: отдельный именованный блок с `:root` и `.dark-mode`. В файле компонента (`button.css`, `post-card.css` и т. д.) переменные только читаются.
