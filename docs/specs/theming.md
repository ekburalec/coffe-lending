# Тематизация компонентов

## Принцип

Компонент не знает о теме. Он использует CSS-переменные (токены), а тема управляет значениями этих токенов через каскад — добавляя класс `.dark-mode` на нужный контейнер.

Переключение темы — это не смена класса на компоненте, а смена контекста вокруг него.

---

## Как это работает

### 1. Компонент использует только токены

```css
/* logo.css */
.logo {
    color: var(--logo-color);
}
```

Никаких хардкоженных цветов. Никаких `.logo--dark` или `.logo--light`.

---

### 2. Токены определяются на двух уровнях

**Светлая тема** — в `:root` (файл `assets/css/base/vars.css`):
```css
:root {
    --logo-color: #000;
}
```

**Тёмная тема** — в `.dark-mode` (файл `assets/css/base/vars.css`):
```css
.dark-mode {
    --logo-color: #fff;
}
```

Когда класс `.dark-mode` появляется на любом предке компонента, CSS-переменные переопределяются и каскадируются вниз — все вложенные компоненты автоматически получают тёмные значения.

---

### 3. Переключение темы на уровне страницы

`dark-mode` добавляется на `<body>` — это меняет тему всей страницы:

```js
document.body.classList.add('dark-mode');    // тёмная тема
document.body.classList.remove('dark-mode'); // светлая тема
```

---

### 4. Нет модификаторов темы на компоненте

Запрещено:
```html
<a class="logo logo--dark">Мой проект</a>
<div class="post-card pc-dark">...</div>
```

Правильно:
```html
<a class="logo">Мой проект</a>
<div class="post-card">...</div>
```

Класс компонента один. Тема определяется контекстом, а не классом на самом элементе.

---

## В дизайн-системе: показ тёмной темы

Чтобы показать компонент в тёмной теме в рамках страницы дизайн-системы (не переключая тему всей страницы), используется обёртка с двумя классами одновременно:

```html
<div class="ds-dark-preview dark-mode">
    <a class="logo">Мой проект</a>
</div>
```

- **`dark-mode`** — активирует тёмные токены внутри этого блока через каскад CSS-переменных (те же правила, что работают на `<body>`)
- **`ds-dark-preview`** — визуальный контейнер: тёмный фон, отступы, скругления

```css
/* ds-page.css */
.ds-dark-preview {
    background-color: #1A1D22;
    border-radius: var(--radius-lg);
    padding: var(--space-6);
}
/* Никаких токенов здесь — ими управляет .dark-mode */
```

Компонент внутри не меняется — меняется только контекст.

---

## Итог: полная цепочка на примере `.logo`

```
vars.css:
  :root       { --logo-color: #000; }   ← светлая тема
  .dark-mode  { --logo-color: #fff; }   ← тёмная тема

logo.css:
  .logo { color: var(--logo-color); }   ← только потребляет токен

logo.html (DS):
  <!-- светлая -->
  <a class="logo">Мой проект</a>

  <!-- тёмная (в DS-превью) -->
  <div class="ds-dark-preview dark-mode">
      <a class="logo">Мой проект</a>
  </div>
```

Это полная цепочка. Компонент — один. Токены — два набора. Переключатель — класс `.dark-mode` на контейнере.
