# Подарочные наборы Coffe & Go

## Статус

Согласованное направление учебного проекта: готовые наборы и возможность собрать
свой подарок. Ассортимент, комплектация и демонстрационные цены находятся в
[описании продукта](../product.md#согласованные-подарочные-наборы).
По последнему решению пользователя товары доступны через корзину лендинга и на месте.
Интерфейс самовывоза реализован в HTML/JS, фактическая отправка заказа не подключена.

## Правила

- Три готовых набора: кофе 250 г с чашкой, кофе 250 г с термосом, три разных кофе по 250 г.
- В цену готового набора включена подарочная упаковка; повторно её не прибавляем.
- Для первых двух наборов фиксирован шоколадно-ореховый кофе «Бразилия».
- В наборе «Три вкуса» — по 250 г каждого согласованного профиля, всего 750 г.
- Для своего подарка гость выбирает кофе и фирменные вещи; цена равна сумме товаров
  плюс отдельно оплачиваемая упаковка. Текущий демонстрационный тариф упаковки — 200 ₽.
- Можно бесплатно смолоть покупаемый кофе под способ приготовления.
- Товары можно добавить в корзину. Свой подарок — отдельные товары и коробка;
  готовые наборы уже включают коробку. Самовывоз и оплата при получении.
- Перед реальным запуском подтвердить комплектацию, цены, вместимость упаковки и наличие.

## Проверка

У готовых наборов цена уже содержит упаковку. При своём составе упаковка учитывается
один раз. Страница не обещает скидку, бронь и гарантированное наличие.
