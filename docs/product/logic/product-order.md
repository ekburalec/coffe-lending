# Порядок товаров

Категории задают группы; порядок товара действует внутри его категории и совпадает
в админке, меню и корзине. Перетаскивание сохраняется сразу после отпускания.
Идентификаторы, цены, наличие и состав не меняются. Перетаскивание между категориями
не выполняется: для этого служит поле категории в карточке редактирования.
Новый товар добавляется последним. Скрытые/отсутствующие позиции можно переставлять;
публичный вывод применяет фильтры видимости после сортировки.
Если другая вкладка изменила порядок или состав категории, устаревший запрос
отклоняется целиком. После ошибки визуальный порядок откатывается; нужно обновить
страницу. Модуль: ../../modules/admin-reorder.md.

По отдельному решению пользователя пункты навигации и FAQ также переставляются
перетаскиванием внутри своей коллекции. Сохраняется полный список включая скрытые
записи. Изменяется только порядок, видимость/содержимое сохраняются. Порядок совпадает
с публичными меню и вопросами; API защищён сессией/CSRF и версией списка.
