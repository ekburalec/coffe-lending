# Редакторы админки

/admin/edit?section=... — список, id=... — запись, new=1 — создание.
Контроллер использует белый список разделов config/admin.php, валидатор готовит
ошибки каждого поля; шаблон выводит формы с label, aria-describedby и CSRF.
Все сохранения и удаления POST, после успеха redirect. Удаление требует отдельной
галочки, занятую категорию удалить нельзя. ID стабилен и создаётся сервером.
products: целые цены, категория, порция, состав, описание, фотография/alt, порядок,
видимость и наличие. categories: название, порядок, видимость.

contacts: название, город, адрес, телефон, карта HTTP(S). hours: семь фиксированных
дней; exceptions: одна запись на дату, закрыто или часы внутри суток. Исключение
приоритетнее дня недели, часовой пояс Asia/Yekaterinburg. Даты и время валидируются.
