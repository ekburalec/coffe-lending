## Цветовая палитра

| Роль | Переменная | HEX | Где используем |
|------|------------|-----|----------------|
| Фон страницы | `--color-bg` | `#…` | Основной фон |
| Поверхность | `--color-surface` | `#…` | Чередующиеся секции, карточки |
| Заголовки | `--color-heading` | `#…` | Заголовки, логотип |
| Основной текст | `--color-text` | `#…` | Текст абзацев |
| Второстепенный текст | `--color-text-muted` | `#…` | Подписи, мета |
| Линии | `--color-line` | `#…` | Разделители, обводки |
| Акцент | `--color-accent` | `#…` | Кнопки, ссылки, активные состояния |
| Акцент hover | `--color-accent-dark` | `#…` | Hover/active кнопок |
| Тёмная секция | `--color-dark-bg` | `#…` | Фон тёмных секций и подвала |

Правила:

- Один цвет действия: кнопки и ссылки — только акцентом.
- Контраст текста — WCAG 2.1 AA: 4,5:1 для обычного текста, 3:1 для крупного. Нарушения
  записываются сюда явно, с решением пользователя.
- Тёмная тема (`.dark-mode`) — нужна / не нужна; тёмные секции — какие.
