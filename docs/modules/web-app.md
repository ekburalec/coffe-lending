# Веб-приложение («На экран Домой»)

Лендинг можно добавить иконкой на домашний экран iPhone/iPad и установить на Android.
С иконки страница открывается как приложение: без адресной строки Safari, в отдельном окне.

## Файлы

| Файл | Что делает |
|------|------------|
| `assets/icons/favicon.svg` | Общий векторный знак для вкладки и веб-приложения (`sizes: any`, `purpose: any`) |
| `manifest.webmanifest` | Имя (`name`) и короткое имя (`short_name`, до 12 символов), `display: standalone`, цвета, иконки |
| `assets/icons/apple-touch-icon.png` | Иконка для iPhone/iPad, 180×180, непрозрачная (углы скругляет iOS) |
| `assets/icons/icon-192.png`, `icon-512.png` | Иконки манифеста (`purpose: any`), квадрат без скруглений |
| `assets/icons/icon-maskable-512.png` | Иконка для Android с маской: знак уменьшен до 78%, чтобы влезть в безопасную зону |
| `index.html`, `<head>` | `<link rel="manifest">`, `apple-mobile-web-app-*`, `mobile-web-app-capable`, `theme-color` |

Все иконки используют один знак из `assets/icons/favicon.svg`: монограмму «ВП»
медного цвета на кофейном фоне. SVG растеризован локальным Chrome, размеры PNG
подготовлены через PHP GD. Фон непрозрачный; maskable уменьшен до 78%.
В манифесте напрямую подключён `favicon.svg`, а PNG нужны платформам, которым нужны
растровые иконки.

## Как пересобрать PNG из знака (macOS)

1. Сделать два вспомогательных SVG 512×512 вне проекта: `square.svg` — знак на квадратном
   фоне без скругления; `maskable.svg` — то же, но знак уменьшен до 78% от центра
   (`<g transform="translate(256 256) scale(0.78) translate(-256 -256)">`).
2. SVG → PNG 512 px: `qlmanage -t -s 512 -o . square.svg maskable.svg`.
3. Уменьшить через GD (`imagecopyresampled`): `square.svg.png` → `icon-512.png`,
   `icon-192.png`, `apple-touch-icon.png` (180); `maskable.svg.png` → `icon-maskable-512.png`.
4. Обновить `?v=` (ниже).

Вспомогательные SVG и промежуточные PNG в проект не кладутся.

## Версии и обновление значка

В HTML адреса фавиконки, Apple Touch Icon и манифеста содержат `?v=` — первые
10 символов md5 содержимого соответствующего файла. Иконки внутри манифеста
тоже имеют `?v=`. При изменении знака пересоберите PNG, обновите версии иконок
в манифесте, затем версию самого манифеста в HTML. Сборка `dist/` распознаёт
такие адреса и копирует файлы без query-параметров в именах.

Уже установленное приложение может сохранить старую иконку в кеше операционной
системы. На iPhone/iPad удалите старый ярлык, откройте обновлённый сайт в Safari
и добавьте его на домашний экран заново. На Android при сохранении старого
значка переустановите веб-приложение из обновлённой страницы.

## Как добавить на iPhone

Safari → «Поделиться» → «На экран „Домой“». Название под иконкой — `short_name` из манифеста (`apple-mobile-web-app-title`).

## Ограничения

Имя приложения: «Вкусный повод», short_name и apple-mobile-web-app-title:
«ВкусныйПовод» (12 символов). Цвет темы #211813, фон запуска #F7F1E8.

- Офлайн-режима нет (service worker не подключён): без интернета страница не откроется.
- Внешние ссылки (карты, мессенджеры) в режиме приложения открываются во встроенном браузере / Safari.
- `start_url` и `scope` — `./`: страница должна лежать в корне сайта или в той же папке, что манифест.

PHP-фаза: /manifest.webmanifest формируется контроллером из базового файла,
название и описание берутся из текущих контактов и SEO. Иконки остаются ресурсами
версии приложения. Apache направляет маршрут в index.php даже при наличии файла.
