# Отзывы и FAQ: сайт и админка

## Публичный блок

Отзывы находятся между получением и FAQ. Только видимые записи, в порядке
sort_order/id, без копирования примеров или вымышленных авторов из референсов.
Слайдер показывает 3 карточки от 960px, 2 от 640px, 1 на телефоне. Все тексты
сразу есть в HTML. CSS Scroll Snap и нативная прокрутка работают без JS; кнопки
появляются при переполнении. reviews-carousel.js отключает недоступные направления,
обновляет подпись диапазона для скринридера и учитывает prefers-reduced-motion.
Карточка содержит цитату, автора и ссылку-источник с сообщением о новой вкладке.
Рейтинг отображается только при заполненных значении, количестве и источнике.
По новому решению пользователя блок #reviews и пункт «Отзывы» остаются видимыми.
Без видимых записей выводится «Отзывов пока нет», цитаты не выдумываются.
Нет видимых FAQ — нет блока #faq, ссылок и FAQPage в JSON-LD.

## Управление

/admin/edit?section=reviews: рейтинг/источник сверху, карточки отзывов с превью
и действиями, форма добавления снизу. FAQ устроен аналогично. Полные тексты остаются
в редакторе, превью ограничено 340 единицами ширины. Скрытая запись помечена, можно
снова показать. Быстрое скрытие/показ — POST с CSRF. Удаление раскрывает подтверждение,
требует галочки; confirm/alert не используются. Порядок отзывов/FAQ редактируется
числом, кнопок «Выше»/«Ниже» нет. Для товаров действует отдельное перетаскивание.
Автоматические FAQ-ответы в превью совпадают с сайтом. Текстовые поля без HTML.
Рейтинг и отзыв имеют разные DOM-ID, хотя форма каждого содержит поле source.

Проверки: tests/integration.py (CRUD, CSRF, скрытие, удаление, форма внизу, пустые
блоки/навигация); tests/reviews-browser.cjs — только на изолированной базе с шестью
записями review-test-1..6. Примеры в этой базе отмечены [Тест] и не попадают в
рабочий var/site.sqlite или seed.json. Проверены карусель, 3/2/1 карточки, мобильная
ширина, отсутствие JS, тёплая палитра, скрытие и восстановление видимости.
