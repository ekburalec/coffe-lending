# Сборка дистрибутива

Инструмент PHP CLI: `bin/build-dist.php`. Команда: `php bin/build-dist.php`.
Дистрибутив `dist/` пересобирается из исходников; на хостинге PHP не нужен.
Полная спецификация: [deploy.md](../specs/deploy.md).

## Файлы для ИИ-агентов

`llms.txt` содержит название, описание, ссылки на страницы и разделы, а также
`llms-full.txt` с текстом из main и footer. Текст берётся из HTML при каждой сборке.
В индексируемой сборке в оглавление включается ссылка на sitemap.xml.
В итоговый head включённых страниц добавляется rel=describedby на llms.txt.

При глобальном noindex оба файла сохраняются с уведомлением о запрете индексации,
но sitemap не генерируется. Без site_url ссылки относительные (`./`), для работы
под путём репозитория GitHub Pages. При заданном адресе ссылки абсолютные.
Страницы с явным noindex в исходном HTML исключаются. Если таких страниц все —
llms-файлы не создаются и ссылка на них в head не добавляется.
Файлы из deploy/ могут перекрыть результат; такие ручные версии проверяются отдельно.

## Проверки

Проверены четыре случая на отдельной временной копии: без домена с глобальным noindex,
с доменом и noindex, индексируемая сборка с доменом и исходная страница с явным noindex.
Проверены наличие файлов, ссылки, sitemap, уведомления и сохранение запрета обхода.
На хостинге вручную проверить ответы 200, UTF-8, доступ краулеров и отсутствие
блокировки CDN. llms.txt не гарантирует индексацию или цитирование.
