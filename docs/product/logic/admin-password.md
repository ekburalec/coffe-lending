# Пароль администратора

Текущий пароль проверяется перед сохранением нового; подтверждение совпадает
со строкой без обрезания пробелов. Пароль хранится только как password_hash,
успешное изменение отзывает остальные сессии и обновляет текущую сессию/CSRF.
Неудачи проверки текущего пароля ограничены отдельно от обычного входа.

Генератор в браузере только предлагает новый пароль и заполняет подтверждение.
Показ/скрытие и копирование не отправляют запросов и не изменяют учётную запись.
Длина предложения 20 по умолчанию, настраивается от 16 до 64 ASCII-символов.
В интерфейсе этот диапазон подписан как длина в генераторе; общие требования
к сохранению нового пароля (15–128 символов с пределом байт) показаны отдельно.
Исключение 0/O/o/1/I/l для символьной генерации действует всегда, без флажка.
Пользовательские настройки не возвращают эти знаки. Настройки применяются только
по нажатию генерации и не меняют ручной ввод.
При генерации оба новых поля снова скрываются; ошибка не уничтожает старый ввод.
В дополнительных настройках можно выбрать группы, собственную пунктуацию
и исключения. По умолчанию нет требований присутствия категорий; отдельный
флажок гарантирует каждую включённую группу только в сгенерированной строке.
Маленькое пространство вариантов сопровождается советом увеличить длину/набор.
Настройки не сохраняются между посещениями, пароли не сохраняются в браузере.
Альтернативный режим создаёт фразу из 6–8 случайных английских слов (7 по умолчанию)
локального словаря EFF. Разделитель пробел, фильтры отдельных символов не применяются.
Число слов ограничивается заранее по серверному лимиту; фраза не обрезается.
Для смены нужны текущий пароль и явное нажатие «Изменить пароль».
Под новым полем локальный индикатор: четыре сегмента и текстовый статус.
Для ручного ввода оценка ориентировочная, для генератора учитываются параметры
случайного выбора. Редактирование сбрасывает данные генератора. Оценка не меняет
пароль/валидацию, не проверяет утечки и не отправляет данные в сеть.
Проверки выполняются на тестовых данных без замены рабочего пароля.
Модуль и параметры: ../../modules/admin-auth.md.

Новые пароли в форме и CLI: 15–128 Unicode-символов, до 512 байт, без NUL,
с проверкой локального списка слабых полных значений. На PHP без Argon2id
дополнительно сохраняется предел bcrypt 72 байта с явной ошибкой.
Новые хеши используют Argon2id при наличии; прежние bcrypt-пароли принимаются
без нового минимума и без обрезания строки. Обычный вход не меняет хеш.
