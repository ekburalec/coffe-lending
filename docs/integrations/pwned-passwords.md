# Проверка новых паролей через HIBP

Статус: интеграция реализована, по умолчанию отключена. Локальный список слабых
полных значений работает независимо от неё. Не выдавать локальную проверку
за проверку всех известных утечек.

Включение на сервере: переменная окружения `APP_PASSWORD_HIBP=1`.
Другие значения не включают интеграцию. Настройка читается `config/passwords.php`.
На странице пароля показано, включена ли онлайн-проверка. Для HTTPS-запросов
нужны OpenSSL, `allow_url_fopen` и рабочее хранилище доверенных сертификатов PHP.
Для локальной разработки и без внешней связи оставить проверку отключённой.

Сервер проверяет только полностью выбранный новый пароль при создании,
CLI-сбросе или смене после локальной валидации, проверки текущего пароля
и подтверждения. Обычный вход, генерация и нажатия клавиш не вызывают HIBP.

Вычисляется SHA-1 от исходной строки UTF-8. В запрос
`GET https://api.pwnedpasswords.com/range/{prefix}` попадают только первые пять
шестнадцатеричных знаков. Заголовок `Add-Padding: true`, таймаут 4 секунды,
редиректы запрещены, проверка TLS включена, тело ограничено 200000 байтами.
Остаток хеша сравнивается на сервере; строки padding с количеством 0 игнорируются.
Пароль и полный хеш не уходят третьей стороне и не пишутся в логи.
SHA-1 используется только для поиска; хранилище пароля остаётся Argon2id/bcrypt.
Сервис видит префикс и IP сервера, поэтому проверка включается явно.

Совпадение с ненулевым количеством запрещает установку нового пароля.
Ошибка сети, таймаут, HTTP-ошибка, пустой/неправильный ответ не считаются
отсутствием утечки: смена/создание прекращается с понятным сообщением,
прежний хеш остаётся действующим. Вход существующим паролем продолжает работать.

Код: `app/services/pwned-passwords.php`, вызовы из `app/services/auth.php`
и `bin/create-admin.php`. `tests/password-policy.php` проверяет префикс,
сравнение остатка, padding, совпадение, отсутствие совпадения и недоступность
на искусственном транспорте без отправки реального пароля в сеть.
`tests/pwned-passwords-http.py` поднимает изолированный стенд с включённой
проверкой и запрещёнными исходящими запросами: обычный вход работает,
ошибки текущего пароля/подтверждения проверяются раньше сети, неудачная
смена и CLI-сброс оставляют прежний хеш и сеансы.

Источник: [официальная документация HIBP](https://haveibeenpwned.com/API/v3#PwnedPasswords).
Рабочие пароли и тестовые пароли реальным запросом к сервису не проверялись.
HTTPS-транспорт отдельно проверен на искусственном префиксе `00000`:
успешный HTTP-ответ с padding получен, без пароля и полного хеша.
