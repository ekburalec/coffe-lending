# Мобильная навигация

Реализация: assets/js/modules/site-navigation.js, initSiteNavigation().
Инициализация через main.js. Хуки: data-site-header, data-navigation,
data-navigation-toggle. Подписи кнопки находятся в HTML.

Без JavaScript ссылки видны и доступны на всех размерах. С JavaScript ниже 960px
кнопка раскрывает навигацию под шапкой. Пункты идут вертикально друг под другом,
ссылки занимают всю ширину строки, текст выровнен по центру.
При переходе по ссылке навигация закрывается.
Escape закрывает меню и возвращает фокус на кнопку.
Состояние синхронизировано с hidden и aria-expanded.

От 960px ссылки видны, кнопка скрыта. При смене размера экрана фокус не остаётся
на скрытом элементе. Модального окна и ловушки фокуса нет.

Ссылка «Заказать» в шапке скрыта до 1010px включительно, чтобы не переноситься
на вторую строку. Корзина остаётся доступной.

Проверены Enter, Escape, смена размера и доступность навигации без JS.

С фиксированной шапкой работает совместно с [fixed-header.md](fixed-header.md).
Раскрытие меню меняет резервируемую высоту; переход по ссылке закрывает меню
до расчёта отступа якоря. На низком экране шапка имеет внутреннюю прокрутку.
