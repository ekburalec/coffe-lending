# Заказы: правила следующей фазы

Разрешено пользователем 28.11.2026: весь каталог, доставка по Екатеринбургу,
самовывоз, ручная обработка, без онлайн-оплаты. Варианты являются отдельными товарами.

Рабочие допущения для разработки: доставка 200 ₽, бесплатно от 1000 ₽,
минимум 0 ₽. Пользовательские настройки сохраняются. Только узнаваемый исходный демо-тариф
150 ₽ / радиус 3 км однократно заменяется на 200 ₽ / Екатеринбург. Адрес подтвердит менеджер.
Приём по умолчанию выключен. Включение требует заполненных реквизитов политики.
Имя и телефон обязательны; фамилия/e-mail добровольны. Для доставки обязательны
улица и дом; дополнительные адресные сведения добровольны.

Готовые напитки и десерты: по готовности только в часы работы. Заказы только из
зёрен/мерча допускают желаемое время в ближайшие 30 дней, в рабочие часы;
менеджер подтверждает время. Смешанная корзина работает по правилам напитков.
Последний приём по умолчанию за 30 минут до закрытия, настройка изменяема.

Доставка: new → contacted → processing → courier → delivered.
Самовывоз: new → contacted → processing → ready → collected.
Отмена любого активного заказа: cancelled, причина необязательна.
Назад и из завершённого заказа: отдельная команда с обязательным пояснением.
Каждая правка проверяет версию и сохраняет событие. До передачи курьеру/готовности
можно менять контакты, состав, время; цены прежних строк сохраняются, новые из каталога.
Снимок тарифа неизменен; сумма пересчитывается. Оплата не отслеживается.

Клиентская цена не считается достоверной. Сервер проверяет наличие, график,
количество и актуальность расчёта. Уникальный ключ POST исключает дубли.
Заказ, строки, история и задания почты создаются одной транзакцией.
Сбой почты не удаляет заказ. Письма автоматически только при создании.

Два календарных месяца после завершения/отмены: обезличивание контактов,
адреса, комментариев, истории и удаление заданий почты. Активные заказы сохраняются.
Копии с заказами старше двух месяцев удаляются задачей очистки, независимо от
префикса. Почтовые ящики очищает владелец. После восстановления очистка обязательна.
Полный откат БД с заказами требует отдельного подтверждения и предварительной копии.

Публичный запуск требует реальных реквизитов, адреса/контактов, утверждённой зоны,
проверенной почты, cron и HTTPS. Документ политики является проектом для согласования.

Факт реализации: операционный тип товара prepared/beans/merch задаётся в админке.
Категории зёрен и мерча создаются пустыми; реальные товары и фото добавляет владелец.
