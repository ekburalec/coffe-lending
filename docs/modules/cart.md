# Модуль корзины HTML-лендинга

`assets/js/modules/cart.js`, initCart() вызывается из main.js после notify.
Каталог — атрибуты data-product-* в index.html. PHP и API отсутствуют.
[Правила покупки](../product/logic/cart.md).

- Кнопка со счётчиком в фиксированной шапке.
- Нативный dialog: закрытие по Escape, кнопке и фону за панелью; браузер удерживает
  фокус внутри и возвращает при закрытии.
- Строки клонируются из template, значения вставляются через textContent.
- Изменение количества пересчитывает итог и восстанавливает фокус.
- Фасовка и помол выбираются под карточкой кофе; все select имеют label.
- Форма самовывоза — второй шаг в диалоге, с возвратом к товарам.
- На мобильном диалог во всю ширину, на десктопе панель справа.
- Чтобы поместить корзину, мобильная навигация теперь используется до 1023 px.
- Без JS покупочные кнопки отключены, каталог и контакты доступны.

Проверены ширины 320, 360, 390, 768, 1024 и 1440 px: нет переполнения;
высота шапки совпадает с отступом. Проверены суммы, варианты, localStorage,
удаление, пустое состояние, Escape, поля формы, отсутствие отправки и хранения контактов.
Ошибок JS и 404 не найдено.

Вручную проверить клавиатуру в модальном окне, большую корзину и реальный телефон.
Реальная отправка, серверная валидация и подтверждение заказа ещё не реализованы.
