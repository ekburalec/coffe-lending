# План внедрения PHP-админки

Решение пользователя: PHP-сайт и `/admin` на одном хостинге, SQLite, один
администратор. Общие данные выводятся из настроек; свободные тексты редактируются
вручную. Все согласованные возможности включены, кроме меток товаров.
Реальные заказы и оплата не входят в задачу. Демо-данные сохраняют свой статус.

Этапы выполняются строго по порядку. Каждый этап — отдельный коммит с кодом,
документацией, проверками и обновлением этого файла. Галочка ставится только
после проверки результата. Первоначально все пункты не отмечены.

- [x] 1. Спецификация — поля, зависимости, архитектура, критерии приёмки и правила проекта.
  Коммит: `docs: specify PHP admin scope and architecture`.
- [x] 2. Основа PHP — фронт-контроллер, роутер, шаблоны, ошибки и настройки; проверка запуска.
  Коммит: `feat: add PHP application foundation`.
- [x] 3. SQLite — схема, миграции, импорт текущего контента без перезаписи при повторном запуске.
  Коммит: `feat: add SQLite schema and initial content`.
- [x] 4. Авторизация — CLI-создание администратора, вход, выход, сессии, CSRF, ограничение попыток.
  Коммит: `feat: add secure admin authentication`.
- [x] 5. Каталог — категории, товары, цены, состав, порции, порядок, видимость, наличие и WebP 1x/2x.
  Коммит: `feat: add catalog and product image management`.
- [x] 6. Контакты и график — адрес, телефон, карта, расписание по дням, исключения по датам.
  Коммит: `feat: add contacts and opening hours management`.
- [x] 7. Получение — тарифы, порог, зона, сроки, включение самовывоза и доставки.
  Коммит: `feat: add pickup and delivery settings`.
- [x] 8. Контент — тексты, изображения, навигация, FAQ, объявления по датам, отзывы и рейтинг.
  Коммит: `feat: add landing content and navigation management`.
- [x] 9. Лендинг — серверный вывод всех управляемых данных, согласованная корзина, без JS читается меню.
  Коммит: `feat: render landing from managed content`.
- [x] 10. SEO — title, description, Open Graph, превью и JSON-LD из актуальных данных.
  Коммит: `feat: add SEO and social preview management`.
- [x] 11. Копии — экспорт БД и полного архива, проверка восстановления, предварительная копия текущих данных.
  Коммит: `feat: add backup and restore tools`.
- [x] 12. Публикация — PHP-дистрибутив, закрытые служебные файлы, сохранность данных, установка и итоговые проверки.
  Коммит: `build: prepare PHP deployment and release checks`.

Этап 2: PHP lint основы успешно выполнен; роутер ограничивает доступ публичными ресурсами. HTTP-проверка будет расширяться вместе с приложением.

Этап 3: импортировано 9 товаров; миграция успешно выполнена дважды. Начальные отзывы и ссылка карты пусты.

Этап 4: изолированные HTTP-тесты миграции, входа, ротации CSRF, отклонения неверного токена и закрытых путей прошли. GD/ZIP доступны через -d extension=gd -d extension=zip.

Этап 5: HTTP-тест создаёт категорию и товар с фото, проверяет обе версии WebP, отрицательную цену, запрет SVG и удаление занятой категории.

Этап 6: проверены сохранение контактов, отклонение javascript-ссылки, неверного интервала часов и повторной особой даты.

Этап 7: HTTP-тесты проверили смену тарифов, работу только с доставкой, запрет отключения обоих способов и дробного порога.

Этап 8: все редакторы открываются; тесты отклоняют неверный якорь, обратный интервал объявления и рейтинг без источника.

Этап 9: HTTP-тесты проверили единый вывод товаров/контактов/тарифов и недоступный товар, локальные границы объявлений и особый график. Playwright: корзина ниже/на/выше порога, пустое состояние, Escape, адаптив 320/768/1440 и ресурсы без ошибок.

Этап 10: HTTP-тест меняет SEO-тексты, проверяет экранирование HTML и JSON-LD с актуальным адресом, ценой и тарифами FAQ.

Этап 11: изолированно проверены SQLite/ZIP-экспорт, отказ для повреждённой БД и ZIP с обходом пути, восстановление адреса и удалённых медиа, автоматическая полная копия перед заменой и отзыв сессий.

Этап 12: PHP-дистрибутив (92 файла) собран без рабочих данных; конфигурация релиза
хранит БД/медиа вне публичного корня. Исходники и dist прошли изолированные HTTP-тесты,
все PHP/.tpl — lint. Проверены настоящий локальный Apache/.htaccess и браузерные
сценарии сборки, включая отсутствие JS и пустую навигацию. Обновлены README,
реестры и инструкции установки/обновления. GitHub Pages заменён ручной сборкой
артефакта без публикации. Подробности: docs/product/admin-qa.md.

Локальный просмотр: http://localhost:8090/admin; доступ в var/admin-access.json,
не включён в git/dist. На внешнем хостинге аккаунт создаётся отдельно. Хостинг и
домен не предоставлены; внешняя публикация, HTTPS и настройки целевого сервера
остаются отдельным ручным шагом. noindex сохранён. Формальная сертификация
WCAG/W3C и пользовательский тест пяти секунд с участниками не проводились.
