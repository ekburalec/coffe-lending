# Проверка PHP-админки

Дата: 25 ноября 2026. Все 12 этапов реализованы локально; внешней публикации нет.
Исходники PHP 8.2.12 и собранный dist проверены на Windows. Серверная часть следует
MVC на функциях, SQLite/PDO, шаблонам .tpl; CSS/BEM и нативный JS сохранены.

## Автоматические проверки

- PHP lint всех 87 PHP/.tpl-файлов исходников и дистрибутива: без ошибок.
- tests/integration.py отдельно для исходников и dist: временные SQLite/медиа,
  миграция, создание администратора, вход, ротация CSRF, отказ неверному токену,
  блокировка после пяти ошибок, закрытые HTTP-пути.
- Категория и товар: создание, WebP/retina, запрет отрицательной цены и SVG,
  запрет удаления занятой категории, скрытие категории, отсутствие товара.
- Контакты и карта: HTTP(S), отказ javascript. График: интервалы, исключения,
  повтор даты, проверка праздника в Asia/Yekaterinburg.
- Доставка: нельзя отключить оба способа, можно оставить только доставку,
  проверяются целые тарифы/пороги. Серверные значения совпадают с корзиной.
- Тексты, навигация, FAQ, объявления, отзывы/рейтинг и SEO: изменения отражаются
  в HTML, произвольный HTML экранируется. JSON-LD содержит текущие цены/контакты/FAQ.
- Объявления: начало/окончание включительно, следующая минута выключает показ.
- robots/llms/манифест используют живые данные, noindex-sitemap недоступен.
- Повторная миграция сохраняет изменения и дополняет отсутствующее фиксированное поле.
- Экспорт SQLite/ZIP, отказ повреждённой БД и ZIP с ../; полный архив восстановил
  изменённый адрес и удалённые медиа, создал предварительную копию и отозвал сессию.
