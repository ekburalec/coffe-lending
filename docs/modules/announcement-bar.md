# Бегущая строка над навигацией

Файлы: assets/css/blocks/announcement-bar.css и assets/js/modules/announcement-bar.js.
Инициализация: initAnnouncementBar() через main.js. Хуки: data-announcement-*.

Тексты находятся в HTML и landing-content.md, факты взяты из product.md:
часы работы, самовывоз без доплаты, бесплатная доставка от 1000 ₽.
Роль блока: короткая информация об условиях до перехода к меню.

Две одинаковые группы движутся справа налево через CSS transform с постоянной скоростью.
Дубликаты скрыты от скринридера; отдельный статичный абзац озвучивает факты один раз.
При наведении или клавиатурном фокусе CSS приостанавливает анимацию. После ухода
указателя и фокуса она продолжается с того же места. Отдельной кнопки нет.
Строка доступна по Tab и имеет имя «Информация кофейни». Класс is-running
определяет только включение анимации при отсутствии reduced-motion.

При prefers-reduced-motion строка не движется, факты переносятся по ширине,
дубликат скрыт. Изменение настройки учитывается без перезагрузки.
Без JS факты также показаны статично. Цвета, размеры и длительность находятся в vars.css.

Проверены остановка при наведении и фокусе, reduced-motion, отсутствие горизонтального переполнения,
режим без JS и аудит axe-core без выявленных нарушений.
