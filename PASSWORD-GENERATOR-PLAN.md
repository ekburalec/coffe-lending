## Текущие решения

| Область | Правило |
|---------|---------|
| Случайные символы | 20 по умолчанию, длина 16–64 ASCII-символа |
| Похожие символы | `0 O o 1 I l` всегда исключены из символьной генерации; флажка нет |
| Пользовательские настройки | Группы, свои знаки, дополнительные исключения; не возвращают похожие символы |
| Категории | Разрешение группы не гарантирует её присутствия; отдельный режим гарантирует все группы |
| Фразы | 6–8 случайных слов EFF, 7 по умолчанию, разделитель пробел; при bcrypt максимум 7 |
| Фильтры фразы | Слова сохраняются целиком, фильтры отдельных символов не применяются |
| Применение настроек | Только по кнопке генерации, без замены уже введённой строки |
| Скрытие | Оба новых поля скрываются после генерации; глазик не меняет пароль и оценку |
| Копирование | Только по нажатию; при отказе понятный ручной вариант |
| Индикатор | Четыре сегмента и статус под новым паролем; оценка локальная и ориентировочная |
| Палитра | Существующий медный акцент и фон линий админки, включая тёмную тему |
| Сервер | Новый пароль 15–128 Unicode code points, до 512 байт, без NUL |
| Хеширование | Argon2id при наличии; fallback bcrypt с явным пределом 72 байта |
| Прежние пароли | Старые bcrypt-пароли принимаются без нового минимума и без обрезания |
| Смена | Текущий пароль, подтверждение, POST/CSRF, ротация ID/CSRF и отзыв остальных сеансов |
| Слабые значения | Локальный список полных значений и производных логина, одинаково для формы и CLI |
| HIBP | Готовая необязательная интеграция, по умолчанию отключена; APP_PASSWORD_HIBP=1 включает её |
| Меню | «Пароль» отделён от «Визуального редактора» бордером, порядок и переходы сохранены |
| MFA | Только проект в отдельном документе, без изменения действующего входа |

Генератор только предлагает пароль. Учётная запись меняется после явного сохранения
с правильным текущим паролем. Настройки генератора не ограничивают ручной ввод.
Подписи различают «Требования к новому паролю» (15–128 символов с пределом байт)
и «Длину в генераторе» (16–64 символа). Более узкий диапазон генератора является
допустимым выбором внутри общих требований, а не вторым правилом сохранения.
Без JS обычный вход и ручная смена работают, неработающие инструменты скрыты.

## Индикатор надёжности

Показывать только под новым паролем, без добавления проверки на странице входа.

| Параметр | Значение |
|----------|----------|
| Высота | 6 px |
| Ширина | 100% ширины поля |
| Отступ от поля | 8 px за счёт существующего gap формы |
| Сегменты | 4, зазор 4 px, скругление существующим radius-pill |
| Подпись | 13 px, «Оценка: Слабый / Средний / Надёжный / Отличный» |
| Пустое поле | Все сегменты пустые, «Введите пароль» |
| Цвета | Существующие admin-line, admin-link-color и admin-muted-color |
| Доступность | role=meter, aria-valuenow/valuetext, связанная подпись, aria-live |

Не добавлять отдельные красную/жёлтую/зелёную палитры и не менять цвета сайта.
Количество заполненных сегментов и текст передают состояние без опоры только на цвет.

Для ручного ввода используется консервативная эвристика длины, разнообразия,
очевидных повторов, последовательностей и небольшого набора слабых значений.
Ручному вводу не приписываются точные биты энтропии или время взлома; максимум
«Надёжный». Это подсказка, не полноценный анализ словарных атак или проверка утечек.

Для результата генератора используются известные параметры случайного выбора.
Очевидные слабые шаблоны имеют приоритет над оценкой пространства. Ручной input/change
сбрасывает данные генератора. Переключение настроек само по себе не меняет оценку
строки, которая уже находится в поле. Показ/скрытие и копирование не меняют уровень.
Никаких запросов, логирования или сохранения пароля для оценки нет.

## Алгоритмы

### Равномерные символы

После автоматического исключения шести похожих знаков базовый алфавит имеет 58
символов. Алфавит очищается от дублей и пользовательских исключений.
Индекс выбирается через crypto.getRandomValues с отбрасыванием:

```text
N = число уникальных разрешённых символов
limit = floor(256 / N) * N
Байты >= limit отбросить; для остальных индекс = byte % N.
Повторять до нужной длины с ограничением числа попыток.
```

Для N=58 принимаются байты 0…231. Фиксированная маска &63 и простой остаток
без отбрасывания не подходят для изменяемого алфавита.
Если включена гарантия категорий, отбрасываются целые кандидаты до выполнения
условия, максимум 256; ошибка не уничтожает ранее введённый пароль.

### Фразы

7776 уникальных слов EFF, без изменения состава/порядка, включая четыре слова
с внутренним дефисом. Uint16Array, порог отбрасывания 62208, индекс по модулю 7776.
Повторы слов допустимы. Максимум длины слова 9, число слов заранее ограничивается
серверным пределом. Фраза не обрезается. Атрибуция CC BY 4.0 включена в dist.

### Данные для индикатора

- Символы без обязательных групп: H = L × log2(N).
- Обязательные группы: нижняя граница H = (L-k) × log2(N) + сумма log2(размера группы).
  Группы не пересекаются; не выдавать эту границу за точную энтропию ограниченного режима.
- Фразы: H = W × log2(7776).
- Уровни для генератора: менее 50 бит слабый, менее 70 средний, менее 100 надёжный,
  от 100 отличный. Это внутренние ориентиры интерфейса, не норматив NIST.
- Событие password-generated передаёт только число entropyBits, без самой строки.
- Ручное редактирование удаляет эту оценку и включает эвристику ручного ввода.
