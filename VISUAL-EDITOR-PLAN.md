# Визуальное редактирование лендинга

Дата: 28 ноября 2026. Статус: выполнено, исходники и PHP-дистрибутив проверены.

## Согласованные решения

- Внизу меню админки отдельная группа: «Пароль», затем «Визуальный редактор».
- По уточнению пользователя редактор работает непосредственно на сайте после входа. Верхняя панель и кнопка «Редактор сайта» переключают правку/просмотр; отдельной страницы, iframe и искусственных размеров нет.
- Разрешённые тексты подсвечиваются, изменяются непосредственно на странице. Панель: сохранение, отмена, счётчик изменённых элементов.
- Жирный/курсив и Ctrl+B/Ctrl+I; без произвольного HTML, ссылок, цвета и размера шрифта. Серверный белый список strong/em/br.
- Типографика: неразрывные пробелы после коротких слов и между числом/единицей. Структурные акценты шаблона сохраняются.
- Alt и замена фотографий самостоятельных блоков доступны по клику на изображение; WebP 1x/2x. Публикация только общей кнопкой.
- Товары, напитки, зерно, категории, контакты, часы, доставка, соцсети, FAQ/отзывы и их фотографии редактируются в прежних разделах. Навигация исключена.
- Для защищённых данных показываются подсказки и переход к соответствующей записи. Общие заголовки секций разрешены.
- Рабочие данные остаются в SQLite; старые тексты/копии совместимы. Сессия и CSRF общие с админкой, cookie Path=/. Все страницы сохраняют frame-ancestors none.
- Несохранённые правки сохраняются в редакторе при ошибках; предупреждение об уходе, защита конфликтов вкладок, согласованная публикация текста и фото.

не содержит панели/меток/CSRF, сессия без cookie не запускается.
