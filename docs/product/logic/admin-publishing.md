# Публикация управляемых данных

Сохранение в админке меняет SQLite. Следующий HTTP-запрос получает новые данные,
уже открытая вкладка обновляется вручную. Числа и общие поля берутся из настроек;
свободные тексты обновляются вручную. Скрытая категория скрывает её товары и пункты
навигации к ней. Ссылки CTA на скрытые исходные категории ведут к общему меню.
Нет в наличии: карточка видна, добавление недоступно, строка корзины не создаётся.
Объявления фильтруются по локальной минуте, границы включительно. Особый график
приоритетнее обычного. Блок отзывов всегда виден с пустым состоянием либо карточками. По отдельному
поручению пользователя добавлены явно помеченные демо-примеры; они не являются
доказательством и не влияют на рейтинг. Рейтинг выводится только с реальным источником.
Первый экран сохраняет утверждённый оффер. Заголовок не обещает выдуманных сроков
или уникальности; 4U не используется для добавления искусственной срочности.

Социальные названия, подписи и адреса хранятся в settings.social
(для старых БД подхватываются URL из контактов); пустой URL означает заглушку без внешнего
перехода. Новый короткий H1 и сценарии поводов согласованы поручением пользователя.

У каждой соцсети есть независимая видимость: выключение убирает ссылку с лендинга,
сохраняя её данные. Общая подпись о пустых URL под соцсетями не выводится.
Если выключены все, блок соцсетей отсутствует. Старые настройки без флага видимости
считаются включёнными. Сохранение работает через POST/CSRF и сразу меняет публичный вывод.

Смена пароля администратора изменяет только хеш в admins, не затрагивая содержимое
лендинга. Требуются текущий пароль, CSRF и подтверждение нового. Текущая сессия
обновляется, остальные требуют нового входа. Подробности: ../../modules/admin-auth.md.

Визуальный редактор публикует разрешённые content/images одной транзакцией,
проверяя версии. До общей кнопки изменения остаются в браузере. Подробнее:
visual-editor.md. Каталог, контакты и остальные структурированные данные исключены.
