# Просмотр состава заказа

Статус: реализовано и проверено в исходниках и dist.
Источник: [product.md](../product.md).

## Сценарий

1. Главная кнопка «Заказать» ведёт к меню.
2. Посетитель добавляет позиции и меняет их количество; позицию можно удалить.
3. В составе видны название, количество, стоимость позиции и общая сумма товаров.
4. Можно выбрать самовывоз или доставку. Самовывоз без доплаты.
   Доставка 150 ₽ при сумме товаров меньше 1 000 ₽; от 1 000 ₽ включительно бесплатно.
   Для пустого состава доставка не начисляется, итог 0 ₽.
   Сумма товаров, доставка и общий итог показываются отдельно.
   Условия вымышленные, источник в product.md помечен [демо].
5. Пустой состав показывает понятное приглашение выбрать позиции из меню.
6. Состав открывается боковой модальной панелью справа по кнопке «Корзина»
   или действию просмотра состава. Добавление товаров само по себе панель не открывает.
7. Панель закрывается кнопкой, по Escape, по затемнению и при переходе к меню.
   Фокус удерживается внутри; при закрытии возвращается на открывшую кнопку,
   а при переходе к меню на заголовок меню. Прокрутка фоновой страницы заблокирована.

## Границы

- Данные меню и цены берутся из HTML, исходные значения зафиксированы в product.md.
- Нет реальной отправки, оплаты и создания заказа. Нельзя показывать успешное оформление.
- Контактные, адресные и платёжные данные посетителя не собираются.
- В интерфейсе достаточно пояснения «Состав заказа не отправляется в кофейню».
  Упоминания учебного статуса проекта не нужны.
- Состав хранится только в памяти вкладки, перезагрузка его очищает.
- Уменьшение количества до нуля удаляет позицию; отрицательных значений нет.
- Счётчик показывает сумму единиц товаров, а не число уникальных позиций.
- После удаления строки фокус переходит к доступному контролу следующей строки
  или к ссылке пустого состояния. Персональные данные не собираются.

Описание модуля: [order-preview.md](../../modules/order-preview.md).

## Проверка после реализации

- Добавление, изменение количества и удаление корректно пересчитывают сумму товаров.
- При самовывозе доплата 0 ₽; доставка проверяется ниже, ровно на пороге 1 000 ₽
  и выше него. Изменение количества пересчитывает доставку и итог.
- Условия совпадают с product.md; выбор получения не подтверждает реальный заказ.
- Пустой состав и работа с клавиатуры понятны и доступны.
- Без JavaScript меню и цены остаются доступны для чтения.
- Никакие данные заказа не отправляются в сеть.
