# GitHub Pages

Конфигурация: `.github/workflows/pages.yml`. Назначение — сборка и публикация
статического дистрибутива `dist/` через GitHub Actions, без серверной части.

Запуск только вручную (`workflow_dispatch`). После checkout и настройки PHP 8.3 с DOM
выполняется `php bin/build-dist.php`. На Pages загружается только `dist/`.
Job публикации ждёт успешной сборки, использует environment `github-pages`
и разрешения `pages: write`, `id-token: write`. Токены в исходниках не хранятся.
Параллельные публикации сериализованы группой `pages`.

Перед запуском: сохранить исходники и workflow в репозитории, в Settings → Pages
выбрать GitHub Actions. Затем Actions → Deploy Pages → Run workflow.
Проверить результат в Actions и открыть URL из environment.

Текущая конфигурация сохраняет `noindex: true`; домен не задан.
Ресурсы используют относительные пути для работы в подпапке репозитория.
`.htaccess` рассчитан на Apache и не настраивает кеш GitHub Pages.
Версии CSS/JS меняются по содержимому при каждой сборке.
llms.txt и llms-full.txt создаются даже в предварительном режиме, с относительными
ссылками и уведомлением о запрете индексации; они не отменяют meta robots.

Локальная сборка и сценарии собранного сайта проверены. Workflow в GitHub
не запускался: удалённый репозиторий в текущем checkout не настроен.
Правила и ограничения: [deploy.md](../specs/deploy.md).
