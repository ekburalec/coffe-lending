# Оформление заказов

Серверные страницы /checkout и /order-success, корзина передаёт ID и количество
через POST, без контактов в URL. Серверная сессия содержит черновик, CSRF и ключ
отправки. Каталог доступен также на /checkout без JS. Контакты не пишутся в localStorage.
Страница успеха доступна только из сессии, no-store/noindex.
Правила: ../product/logic/orders.md. План: ../../ORDER-IMPLEMENTATION-PLAN.md.

Модели выполняют SQL; сервисы проверяют переходы и расчёт; контроллеры принимают
POST и готовят шаблоны. Миграции CLI, целые рубли, до 50 строк и 99 единиц строки.
CLI очистки: php bin/cleanup-orders.php. На хостинге запускать ежедневно.
