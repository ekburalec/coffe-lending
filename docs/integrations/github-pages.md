# GitHub: сборка без публикации

Историческая статическая публикация Pages отключена в PHP-фазе. Workflow
pages.yml удалён, чтобы PHP-код не попадал на статический хостинг. Заменён ручным
.github/workflows/build-php.yml: PHP 8.3 с расширениями, изолированные HTTP-тесты,
сборка dist и артефакт coffee-php-release (с .htaccess/.user.ini). Загружаются только
проверенные файлы dist, рабочих данных и паролей там нет. Артефакт хранится 7 дней.
Workflow не подключается к хостингу и не отправляет данные автоматически.
Внешний запуск GitHub Actions в этом окружении не выполнялся.
